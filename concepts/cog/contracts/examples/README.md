# Worked two-party demo

This directory is a **self-controlled demonstration**, not evidence that an
independent counterparty adopted COG. Both Ed25519 keypairs were generated by
ProofOfWorks for this example. Only the public keys are committed; the demo
private keys were destroyed after signing and have no production trust.

`reference-cdo.json` is a 12-month hybrid obligation: USD 3,000 fixed plus
1,000 cogs per month. The provider and client each signed the identical CDO
bytes under SSH namespace `cog-cdo`.

`reference-invoice.json` settles June 2026. The archive has only two dated
fixes, and only the June 10 publisher matches the CDO publisher priority.
Accordingly the invoice honestly uses `carry-forward`, requires
acknowledgement, and resolves the indexed leg at USD 0.144000 per cog. It does
not manufacture a seven-day history.

From the repository root:

```sh
ssh-keygen -Y verify -f contracts/examples/demo_allowed_signers \
  -I cog-cdo -n cog-cdo -s contracts/examples/reference-cdo.provider.sig \
  < contracts/examples/reference-cdo.json

ssh-keygen -Y verify -f contracts/examples/demo_allowed_signers \
  -I cog-cdo -n cog-cdo -s contracts/examples/reference-cdo.client.sig \
  < contracts/examples/reference-cdo.json

python3 contracts/settle.py --verify contracts/examples/reference-invoice.json \
  --archive fixer/archive \
  --allowed-signers contracts/examples/demo_allowed_signers
```

The last command is also embedded verbatim in the invoice's `recompute` field.
It verifies the detached invoice signature, every referenced archive signature
and SHA-256, the Settlement Fix, Decimal line arithmetic, subtotal, and
canonical invoice identifier.
