# Agent Service-Level Denomination Rider

Template v0.1 — not legal advice

For **$agent_service**, the Provider commits to **$service_level**. The standing
obligation is $cogs_per_period cogs per $period, plus USD
$fixed_usd_per_period. “COG-1 Fix” identifies eligible daily evidence and
“Settlement Fix” identifies the period-end resolution rule.

Failure credits are calculated in cogs before USD resolution so the economic
credit scales with the same reference input as the service obligation.
